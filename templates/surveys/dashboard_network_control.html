Démarrage rapide

Le helper n'est pas embarqué dans Django. Il doit tourner localement sur Windows pour que les actions LAN fonctionnent.

  1. Ouvre PowerShell en administrateur.
  2. Place-toi dans le dépôt du projet.
  3. Lance .\scripts\windows\taf-lan-helper-start.ps1.
  4. Reviens ici puis clique sur Actualiser l'état.

Helper LAN non disponible

Le helper LAN n'est pas joignable.

Cette page reste correcte côté Django, mais les actions LAN dépendent d'un processus Windows local. Utilise les scripts PowerShell suivants : 

.\scripts\windows\taf-lan-sync.ps1          # Configurer l'acces LAN
.\scripts\windows\taf-lan-show-status.ps1    # Afficher l'etat
.\scripts\windows\taf-lan-helper-start.ps1   # Demarrer le helper

Installation du helper (une seule fois, PowerShell Admin) : 

# Depuis le dossier du projet :
.\scripts\windows\taf-lan-helper-start.ps1

Le helper ecoute uniquement sur 127.0.0.1:{{ helper_port }} et n'est pas accessible depuis le LAN.
