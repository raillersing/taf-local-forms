# Interaction et accessibilité

- fournir un lien de saut vers le contenu principal ;
- garder un ordre de focus correspondant au sens du parcours ;
- rendre le focus visible et ne pas changer de contexte au simple focus ;
- viser des contrôles tactiles d’au moins 44 px dans les parcours terrain ;
- permettre le retour après chaque action réseau, export, import ou sauvegarde ;
- afficher une solution avec chaque erreur importante ;
- tester 360 px, 390 px, tablette, bureau et zoom 200 % ;
- respecter `prefers-reduced-motion` et ne pas cacher d’information dans une
  animation ;
- utiliser `details` ou une zone secondaire pour les diagnostics techniques ;
- garder les états non confirmés textuels et explicites.
