# Modèle de verdict

```text
Verdict : APPROVE | REQUEST_CHANGES | BLOCK

1. [Gravité] Titre du constat
   Preuve : fichier, route, état ou scénario
   Impact : conséquence utilisateur ou terrain
   Recommandation : correction ciblée
   Validation : test ou parcours attendu

Points non confirmés :
- élément dont la preuve runtime ou la source métier manque

Hors périmètre :
- sujet volontairement non examiné

Lot minimal recommandé :
- plus petite correction cohérente
```
